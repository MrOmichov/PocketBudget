# Pocket Budget

REST API на Spring Boot для записи и просмотра расходов. Расходы хранятся в PostgreSQL.

## Требования

- JDK 21
- PostgreSQL и пользователь с доступом к базе данных
- Доступ к сети для первой загрузки Maven 3.10.0 и зависимостей; Maven Wrapper включён в репозиторий

## Настройка базы данных

В репозитории нет миграций и настроек подключения к базе по умолчанию. Создайте базу PostgreSQL и задайте параметры подключения через `SPRING_DATASOURCE_URL`, `SPRING_DATASOURCE_USERNAME` и `SPRING_DATASOURCE_PASSWORD`. Приложение использует `spring.jpa.hibernate.ddl-auto=validate`: при запуске оно проверяет схему, но не создаёт её.

Перед запуском создайте в базе следующую таблицу. Её ограничения также соответствуют тестам ограничений базы данных:

```sql
CREATE TABLE expenses (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    amount bigint NOT NULL CHECK (amount > 0),
    category varchar(255) NOT NULL CHECK (category !~ '^[[:space:]]*$'),
    spent_at date NOT NULL
);
```

Например, задайте параметры подключения к локальной базе в PowerShell:

```powershell
$env:SPRING_DATASOURCE_URL = 'jdbc:postgresql://localhost:5432/pocket_budget'
$env:SPRING_DATASOURCE_USERNAME = 'pocket_budget'
$env:SPRING_DATASOURCE_PASSWORD = '<пароль>'
```

## Запуск

В корне репозитория выполните:

```powershell
.\mvnw.cmd spring-boot:run
```

В macOS или Linux используйте `./mvnw spring-boot:run`. Адрес сервера по умолчанию — `http://localhost:8080`.

## API

- `GET /api/health` возвращает `{"status":"UP"}`. Этот endpoint не проверяет подключение к базе данных.
- `POST /api/expenses` создаёт расход и возвращает HTTP 201 с данными расхода и заголовком `Location`. `amount` — целое число от 1 до 9223372036854775807, `category` не может быть пустой или состоять только из пробелов, `spentAt` — дата в формате `yyyy-MM-dd`. Приложение не определяет валюту или единицу измерения суммы.
- `GET /api/expenses?page=0&size=20` возвращает `items`, `page`, `size`, `totalElements` и `totalPages`. Нумерация страниц начинается с нуля; `page` должен быть неотрицательным, а `size` — от 1 до 100. Значения по умолчанию — 0 и 20. Результаты отсортированы по убыванию даты, затем по убыванию ID.

Пример тела запроса:

```json
{
  "amount": 300,
  "category": "food",
  "spentAt": "2026-10-19"
}
```

Заголовок `Location` указывает на созданный расход, но endpoint для получения отдельного расхода по ID пока отсутствует.

## Тесты

Для полного набора тестов нужна отдельная база PostgreSQL с именем `pocket_budget_test`, подключение от пользователя `pocket_budget`, а также таблица и ограничения, приведённые выше. Перед запуском тестов настройте те же переменные подключения, указав тестовую базу. Некоторые тесты удаляют строки внутри транзакции, а значения счётчика ID могут увеличиваться; используйте отдельную тестовую базу.

```powershell
$env:SPRING_DATASOURCE_URL = 'jdbc:postgresql://localhost:5432/pocket_budget_test'
$env:SPRING_DATASOURCE_USERNAME = 'pocket_budget'
$env:SPRING_DATASOURCE_PASSWORD = '<пароль>'
.\mvnw.cmd test
```

В macOS или Linux задайте соответствующие переменные окружения и выполните `./mvnw test`. Тесты проверяют валидацию контроллеров, пагинацию, сохранение данных, ограничения базы и запуск приложения.
